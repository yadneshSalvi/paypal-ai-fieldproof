# Private project Board Packs

Open **Board Pack** from project navigation. Choose a label and capture the current project version. Each saved edition has an original timestamp, event position, source hash and content hash. A repeated capture request returns the same edition. Capturing, reading, printing or exporting a report does not approve or execute a payment.

The report is private to the current project, actor, role and membership version. Organizers receive their authorized project details. Auditors receive the redacted project view. Donors receive their own contribution records alongside clearly separate project totals. Volunteers receive their own authorized expenses; other people's receipts remain private. A saved-workspace switch, role change, expired session or membership change requires opening the desk again in the current profile.

The report distinguishes original gross receipt amounts, credited amounts, completed returns, pending returns, exclusions and excess from the current purpose positions. Paired reallocation and rollover records keep their original receipt identity. Paid principal, actual fees, reserved principal and fee allowances remain separate. Unpaid pledges are not settled funding; an accepted sponsor promise is part of unpaid support, not an additional amount to add again. An earlier merchant balance observation carries its own timestamp and does not certify current provider liquidity or complete reconciliation.

Open a source beside a figure, requirement, image or expense to inspect its saved scope and provenance. Tab and Shift+Tab stay within the source dialog; Escape returns to the original source control. The image control retains keyboard focus while checking access. The return control restores the report and package selection. Reviewed geometry, image association and work review remain distinct from financial support. Sample records identify fictional evidence and payments; they do not establish an independent professional review or physical completion.

A later project change marks an older edition **Historical** while retaining its original facts. A withdrawn or changed bound source permission withholds the edition's content, source details, images and CSV; the immutable capture and audit remain. Every disclosure checks current authority and current source permission again after waits. A current report can become historical when a promise or reviewer scope passes its original deadline. None of these transitions renews that deadline or silently rewrites an edition.

Select **A4** or **Letter**, then choose **Prepare print preview** to inspect the same saved edition without opening the system print sheet. The app checks the selected report, waits for its fonts and decoded permitted images, and checks current authority again. The prepared preview names its original edition, content hash, paper and detail selection. **Print / save PDF** performs the same preparation and opens the browser's print controls.

Changing the edition, paper or purpose selection, a later access check, or an ended session clears print preparation. An unprepared browser print shows a recheck notice and omits private report content. Missing images block preparation until they load or the report is refreshed. The browser's own print engine produces the PDF or paper copy; there is no separately claimed server PDF service. Printed and downloaded copies already received by an authorized reader cannot be recalled after access changes.

CSV exports contain the same authorized frozen report sections and escape spreadsheet formula prefixes. Private image bytes and document paths are not put into browser storage. Saved capture intents support recovery after a lost response; retrying the saved request does not create a second report.

This is a per-project report. Organization portfolios, scheduled treasurer delivery, merchant-wide closed-books reconciliation, independent research and the final demonstration remain separate capabilities and qualification work.

The focus and print-controller regression tests mount the actual React components in the pinned jsdom environment. They require Node 22.22.2 or newer within the supported Node 22 major; qualification uses Node 22.22.3. These controlled DOM tests cover focus boundaries, preparation, expiry and late-response rejection.

The [local native qualification](evidence/board-pack-native-qualification.json) records actual browser keyboard checks, 390px/360px layouts, reduced motion, natural expiry, donor isolation, and ordinary source and access withdrawal. One original Sample edition produced 26-page A4 and 27-page Letter PDFs through the browser print engine; all 53 pages were rendered and inspected. True 200% browser zoom remains unverified. The Letter page 2 orphaned table header is a known layout polish item.
